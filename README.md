# Base Bulk Sender

Send ERC-20 tokens to multiple wallet addresses on the Base network quickly and easily.

## Features

* Send ERC-20 tokens on Base
* Send tokens to multiple wallet addresses
* Bulk token distribution
* Connect your Web3 wallet
* Simple recipient list
* Review amounts before sending
* Direct on-chain transactions
* No coding required
